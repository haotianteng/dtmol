## Codebase Patterns
- UniMol dict files are at `dtmol/pretrain_models/` (NOT `dtmol/models/pretrain/`), plain text with one token per line, no counts
- Dictionary class at `dtmol/utils/dictionary.py` uses special tokens: [PAD]=0, [CLS]=1, [SEP]=2, [UNK]=3
- CrossDataset batch structure uses `net_input` dict with mol_* and pocket_* keys, plus `diffused` dict
- Coordinates are padded with `np.inf`, tokens with pad index 1
- Mypy works with `--ignore-missing-imports` flag since many deps lack stubs
- Converter self-registration: each converter module calls `register()` at bottom, `convert.py` just imports the module
- PDBBind pocket_atoms are full atom names (e.g. 'CA'); use `a[0]` for element symbol
- HDF5 datasets may store strings as bytes — always check and decode if needed
- h5py needed for HDF5-based converters (ANI-2x, SPICE2, MISATO, Transition1x)
- SPICE v1.1.4 uses Hartree for energy and Hartree/Angstrom for gradients (positions in Angstrom); negate gradients for forces; mbis_charges has extra trailing dim (M,N,1) — squeeze it
- Dimer detection: Union-Find on 1.8A covalent cutoff to find disconnected components
- Converter-specific CLI args: add to convert.py argparse, pass as extra_kwargs to converter.convert()
- MISATO component classification: protein = standard AA 3-letter codes, ligand = everything else minus water (HOH/WAT/TIP3)
- BioPython (`biopython` package) needed for PDB/mmCIF parsing; use PDBParser(QUIET=True) / MMCIFParser(QUIET=True)
- Transition1x HDF5 has nested groups — use h5py visititems() to find leaf groups with 'atomic_numbers' + 'positions'
- UnifiedDataset returns batch matching CrossDataset format: `net_input` dict with mol_*/pocket_*/cross_* keys, `pes_tier`, `holo_center_coordinates`
- Single-molecule samples get dummy protein (1 pad token, zero coords) + `single_molecule_mask=True`; decoder must mask cross-attention for these
- Edge type formula: `token[i] * num_dict + token[j]`; cross uses mol dict size as multiplier
- Diffusion samplers: molecule ChainSampler (rot->tr->pert) returns score (2+M, 3), protein ChainSampler (pert only) returns score (P, 3)
- DiffusionDataset pattern: sampler(x) with x shape (1, N, 3), returns (x_t torch, score numpy, norm numpy, ts numpy)
- Save/restore np.random and torch.random state around diffusion calls for reproducibility
- Force targets go in 'diffused' dict as 'mol_real_forces' and 'pocket_real_forces'; 'force_tier' at sample level
- DiffusionTrainer.train_step/valid_step return (loss, loss_dict) tuple; diffusion_loss takes full batch dict (not just diffused_dict)
- dtmol_train_test.py is gitignored — use `git add -f` to stage it
- For PDB parsing in converters: manual line parsing of ATOM records + numpy vectorized distance is 100x faster than BioPython PDBParser for batch processing

- **Learnings for future iterations:**
  - CrossDataset uses np.inf for coordinate padding, 0.0 for distance/displacement padding
  - Edge type formula: token[i] * num_dict_entries + token[j]
  - Cross edge type uses mol token count (num_mol_dict) as multiplier, not protein dict
  - BOS/EOS are added AFTER computing distance/displacement matrices, then 2D/3D matrices are padded with 0.0
